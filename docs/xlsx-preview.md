# XLSX 只读预览

0.3.2 候选修复两处缺口：原先 xlsx 仅被识别为普通附件，没有面板表格渲染；拖入的 xlsx 二进制又会被图片专用校验拒绝。

二进制预览仅在显式打开记录或导入时生成；搜索、索引、上下文和 HTML 导出不预读外置工作簿，也不附带派生预览载荷。一个附件含有多个 xlsx 时，可通过工作簿选择器逐个查看和下载；混合数据页与图表页的工作簿保留普通数据页，跳过图表页。
本轮保持附件身份，给 `.xlsx` 增加派生的 `spreadsheetPreview`。直接放入知识目录的工作簿通过现有 `fs.stat/readRange` 分块读取；导入工作簿继续保存在附件数据中。派生字段不进入记录编码或索引，不迁移原文件，不改变 UUID、路径、记录所有权或宿主权限。

## 可见行为

- 点击文件树的 xlsx 后显示只读数据网格，提供可见工作表标签和每页 100 行的分页。
- 支持共享字符串、富文本片段、内联文本、布尔值、数值、基本数字及日期格式、合并单元格和列宽。中文、文本前导零与原始单元格地址保留。
- 公式显示工作簿保存的缓存结果，不执行或重算；缓存缺失时显示公式文本，并明确提示。原有错误值按文件内容显示，不擅自修复或重写工作簿。
- 工作表加载或解析失败时清空旧数据并禁用分页，返回有效工作表后可恢复，不把上一表的数据冒充当前表。
- 这是数据预览，图表、图片、复杂格式、宏、外部数据源和打印版式不展示；隐藏工作表不列入标签。旧 `.xls`、`.csv` 与 WPS 格式沿用原系统打开路径。
- 原生工作簿提供“在系统中打开”和文件位置；导入的附件提供原工作簿下载。下载保持原字节，不把附件元数据 Markdown 冒充 Excel 原件。
- 切换文件、项目或视图后，过期读取和解析不覆盖当前页面。收起侧栏不重建表格，当前工作表、分页和选择内容保留。
- 0.3.3 候选为每次打开的工作簿创建独立的数字格式器池，最多 32 项，仅保留数字选项，不保存单元格值。多个工作表可复用同一格式；重新打开工作簿得到新池。日期、百分比、金额、前导零、公式缓存和安全限制保持原有规则；仍不代表整张大表已改为分批解析。

## 读取边界

| 项目 | 上限 |
| --- | ---: |
| 工作簿压缩字节 | 10 MiB |
| ZIP 总解压字节 | 32 MiB |
| 单个 XML 字节 | 8 MiB |
| ZIP 成员 | 2048 |
| 可见工作表 | 100 |
| 每表解析单元格 | 200000 |
| 网格显示范围 | 前 2000 行、100 列 |

超出显示范围明确提示；超过资源上限、损坏、加密或不支持的封装停止解析并保留可用文件操作。二进制读取每次最多 64 KiB，异步调用前后核对工作区及最终文件状态。宿主缺少 `readRange` 时不把二进制当文本读取，也不绕过权限使用原生文件系统。

ZIP 不向磁盘解压；核对目录、成员名、长度、局部头及 CRC，拒绝路径穿越、重复/重叠成员、加密和非支持压缩方法。解压流逐块受上限约束，XML 使用浏览器原生解析并拒绝实体/DTD。所有表格文本通过 `textContent` 展示，不插入 HTML，不执行公式，不发起外部链接请求。使用现有浏览器能力，不安装或加载在线表格服务。

## 验收

`spreadsheet-preview.test.cjs` 覆盖真实临时文件系统中的外置/导入工作簿、原字节、大小与读取失败、工作区切换；`renderer/xlsx.test.mjs` 覆盖 ZIP、CRC、解压限制、实体拒绝、取消和基本值格式。新增测试先在发布基线上失败。

`tests/xlsx-flow.py` 通过真实面板、服务和存储验证中文、日期、前导零、合并、公式缓存/缺失、工作表、分页、拖入、原件下载、损坏提示、系统打开失败、过期读取、深浅主题和窄窗口。测试只使用临时项目；现有物料表另作只读比对，源文件哈希保持不变。
