# 可收起文件侧栏

0.3.1 在项目知识库左上角增加侧栏按钮。默认展开，点击“收起侧栏”隐藏文件列表，正文占满可用内容区；同一位置仍保留“展开侧栏”。不增加快捷键，可用原生按钮的 Enter、空格操作，提供本地化标签、`aria-controls` 与 `aria-expanded`。

切换只改变侧栏可见性与布局，不重建文件树、当前正文、编辑器、记忆总览或 HTML iframe。搜索、文件夹展开状态、滚动、选中记录、未保存内容及进行中的自动保存按既有流程保留。隐藏列表不再占用布局空间或进入键盘焦点顺序。窄窗口下同时移除原列表占据的行，内容高度充满剩余区域。

开关状态只保存在当前面板内，切换知识库/记忆或重绘外壳后继续保留；重新打开或整页重载时恢复默认展开。不写项目数据、偏好设置或浏览器存储，不改变原型沙箱及插件权限。

实现为独立的 `renderer/sidebar.mjs`，主界面只接入按钮和挂载点。`tests/sidebar-flow.py` 从真实页面、服务和临时文件系统进入，覆盖鼠标/键盘、可访问状态、内容几何、选择/搜索、进行中的保存、记忆输入、iframe 状态、标签切换、中英标签以及 390/800/1280 宽度的深浅主题。该用例先在无开关的基线上失败，再在实现后通过。
